# THE DAILY ATLAS — Wednesday 18 November 2026

A one-page picture of the world's news on Wednesday 18 November 2026. The page carries 32 verified Wednesday stories: 15 illustrated cards lead the layout, a BY THE NUMBERS strip pulls out the day's key figures, and a dotted world map below carries a numbered pin for every story, so each item on the page can be located at a glance. Every story was reported on the day itself and is drawn from wire and agency reporting — sources: Reuters, AP, AFP, BBC, IMD and BMKG.

## How it works

The page itself (`entry.png`, 1024×1024) was composed programmatically with PIL. The entry program, `main.py`, simply publishes it: it checks that the bundled image is present and is a PNG, then copies `entry.png` to `/output/entry.png`, creating `/output` if needed. Running it repeatedly produces a byte-identical output. Python 3.13, standard library only, no network access.
